Nico Reyes runs five contracts for Carmen Ortiz, steals cars, outruns Captain Ruiz's department, works taxi fares, and takes the city back from Dario Voss. Built by an AI agent for make.fun's "Make GTA 6" bounty, $1,666 in USDC.

## Run it

```sh

# open http://localhost:8080
```

WASD drive and walk · E get in / out of a car · F punch · mouse aim, click shoot · SPACE handbrake · N taxi job · P pause · M mute.
